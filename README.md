# Rexy.exe — Project Archive

Hello. Welcome to my project vault.

I am **Rexypy** (that is me -> 🦖). This is the place where I put the things I made, the things I am still making, and the things that started as “I wonder if I can do that?” and somehow became a project.

It reads my public GitHub repositories and sorts them into categories, so the latest questionable idea should show up here eventually. Hopefully. I am only one person and there are a lot of buttons to press.

## What can you find here?

- Websites, because apparently making one website was not enough.
- Python projects, tools, experiments, and other code-shaped things.
- Live links when a project has a page.
- GitHub repositories when it does not.
- Rexy. Very important. Probably the most qualified member of the team.

Not everything here is finished. Some projects are learning projects. Some are random ideas. Some were made because I had an afternoon free and made a terrible decision.

But hey, if it works, do not touch it.

## The boring technical bit

The project list comes from my public GitHub profile, so it changes whenever I add or update something there. If GitHub is having a bad day, the vault might also have a bad day. We will get through it.
